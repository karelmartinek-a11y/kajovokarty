# SSOT traceability – KájovoKarty 1.1

Tento dokument je odvozená dohledávací matice. Původní vstupní DOCX není součástí distribučního balíku.

- Nalezeno závazných scénářů: **162**.
- Aktuální lokální běh pro změny úhrad prošel **126 testy**; Windows GUI smoke důkaz zůstává oddělený od headless testů.
- Stav `LOCAL_VERIFIED` znamená, že odpovídající čistě lokální unit/integration kontrola v tomto prostředí proběhla.
- Stav `STATIC_EVIDENCE` znamená implementaci a statickou dohledatelnost bez úplného Qt/Windows runtime důkazu.
- Stav `BLOCKED_WINDOWS` znamená, že rozhodující důkaz vyžaduje skutečný Windows 10/11 x64 runner, Qt runtime, DPI nebo instalátor.

Forenzní běh navíc opravil chybný SQL dotaz Booking zdrojů, doplnil živou dohledatelnost všech technických objektů Přílohy B, auditované a vratné řešení konfliktu Booking reference, read-only obnovení účtů a položek účtu, importní idempotenci Better Hotelu a nový přehled dokladů s úhradou kartou. Pravidla tří uživatelských stavů a párování jsou v `docs/PAYMENT_RULES.md`.
